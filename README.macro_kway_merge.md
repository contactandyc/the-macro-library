`macro_kway_merge` provides a single control-flow macro to drive a highly efficient K-way merge using a min-heap. It is designed to combine multiple sorted streams (e.g., sorted arrays, files, or iterators) into a single sorted output.

It relies on the `macro_heap.h` infrastructure to maintain the active "minimum" items from each stream.

---

## Quick start

### 1) Define your stream iterator and heap

You need a struct representing your data stream and a corresponding min-heap (generated via `macro_heap.h`).

```c
typedef struct {
    int current_val;
    int *array;
    size_t index;
    size_t length;
} StreamIter;

/* Assume you've generated a heap for StreamIter tracking the minimum current_val */
typedef struct stream_heap_s stream_heap_t;

```

### 2) Define your process and advance functions

The merge loop needs to know what to do with the smallest item (`process`), and how to pull the next item from that stream back into the heap (`advance`).

```c
static inline void process_stream(StreamIter *iter) {
    printf("Next smallest value: %d\n", iter->current_val);
}

static inline void advance_stream(StreamIter *iter, stream_heap_t *heap) {
    iter->index++;
    if (iter->index < iter->length) {
        iter->current_val = iter->array[iter->index];
        /* Push the updated iterator back into the heap */
        stream_heap_push(heap, iter); 
    }
    // If the stream is exhausted, we simply don't push it back.
}

```

### 3) Run the merge loop

```c
stream_heap_t my_heap = {0};
// ... populate my_heap with the initial state of your streams ...

macro_kway_merge_loop(
    StreamIter,           // type
    &my_heap,             // heap
    stream_heap_pop,      // heap_pop_fn (generated by your heap macro)
    advance_stream,       // advance_fn
    process_stream        // process_fn
);

```

---

## API surface

### `macro_kway_merge_loop(type, heap, heap_pop_fn, advance_fn, process_fn)`

* **`type`**: The bare struct type stored in your heap array (e.g., `StreamIter`).
* **`heap`**: A pointer to your populated `macro_min_heap` instance.
* **`heap_pop_fn`**: The function/macro used to pop the minimum item from the heap. Must return a pointer to `type`.
* **`advance_fn`**: A function/macro with the signature `void advance(type *iter, heap_t *h)`. It is responsible for fetching the stream's next value and pushing the `iter` back into the heap if the stream isn't empty.
* **`process_fn`**: A function/macro with the signature `void process(type *iter)`. It handles the business logic for the extracted minimum item (e.g., writing it to a buffer).

> **Behavioral Note:** The macro copies the popped item to a local variable (`type current = *min_item;`) before calling `process` and `advance`. This prevents pointer invalidation if the heap reallocates or shifts underneath you during the `advance_fn` push.
